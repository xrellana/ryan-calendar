# 工作日程表

一套**零依赖、无构建**的个人工作日程管理工具（纯 HTML / CSS / JavaScript），电脑与手机浏览器打开同一链接即可使用，也可直接部署到任意静态托管站点（GitHub Pages、Cloudflare Pages、Vercel 等）。

## 核心功能

- **月 / 周 / 年三视图**：周一为每周首日，支持月视图跨天整体围合渲染（文字单行居中且仅出现一次、跨周界断点箭头、重叠泳道自动避让）、周视图手机端每天一行、年视图 12 迷你月历与归一化统计。
- **日期底色与农历**：严格按「法定节假日（浅灰+休） → 调休上班日（白底+班） → 普通周末（浅灰） → 普通工作日（白底）」顺序判定，内置 2024–2027 年国务院办公厅放假调休安排、1900–2100 农历、二十四节气与传统节日。
- **自主类别管理**：默认「提交截止」「外出评估」「咨询出差」「休息」，支持新增、改名、28 色预设与自定义取色、删除兜底及上下排序调整同日优先级；新建/编辑日程时标题字色实时跟随类别并自动压暗保可读。
- **《评估项目台账》导入**：纯前端离线解析 `.xlsx` / `.csv` 与 Excel 粘贴内容，自动识别表头、合并单元格沿用上一行、预评估/正式评估拆分为独立日程、导入前预览确认、重复导入去重且不覆盖手填日程。
- **数据安全与迁移**：本地 `localStorage` 存储，支持 JSON 全量备份与恢复、`.ics` 日历导出、压缩同步链接以及保留颜色与底色的单页月视图打印。

## 快速打开与公网访问参数

- **本地预览**：直接用浏览器打开 `index.html`，或在项目目录运行任意静态服务器访问。
- **公网访问限制**：部署到公网域名后，默认要求链接携带访问参数（默认配置在 `js/config.js` 的 `accessGate`，示例参数为 `?k=ryan2026`），缺少参数时入口页拒绝访问；可在 `js/config.js` 中修改 `validTokens` 为你的专属口令。

## 年度节假日更新（NFR-6）

节假日数据独立存放在 `js/holidays.js` 中。每年底国务院办公厅发布下一年度部分节假日安排通知后，只需在 `YEAR_PLANS` 对象内按同样格式追加对应年份数据并更新 `coveredRange.maxYear` 即可，无需改动任何业务逻辑。
